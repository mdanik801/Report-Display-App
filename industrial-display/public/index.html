⚡ How Shared LAN Data Synchronization Works:

  • Central Storage: All pasted Excel rows and settings are saved to data/dashboard_data.json on the host PC.
  • Instant Broadcast: The host server broadcasts updates via Server-Sent Events (SSE) to all open browsers.
  • Automatic Sync: When anyone pastes new Excel data, every other PC updates without needing to refresh!
  • Persistence: Restarting the server or refreshing any browser restores the exact same latest report data.
